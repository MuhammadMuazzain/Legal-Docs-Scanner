# CUAD training resources

Place Contract Understanding Atticus Dataset (CUAD) files here for model fine-tuning.

Recommended contents (not committed due to size):
- `CUAD_v1.json`
- `master_clauses.csv`
- `full_contract_pdf/` — original contract PDFs
- `full_contract_txt/` — text versions

Dataset reference: [Atticus Project / CUAD](https://www.atticusprojectai.org/cuad)

See `Fine_tuning_code.ipynb` in the parent folder for the training workflow.
